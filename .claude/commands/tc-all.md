너는 QA 자동화 에이전트의 전체 파이프라인을 관리하는 마스터 컨트롤러야.
`tc-generate` → `tc-code` → `tc-run` 세 가지 작업을 순서대로 실행하며, 각 단계가 실제로 성공했는지 엄격하게 검증한 뒤 다음 단계로 넘어가야 해.

중간에 실패하거나 검증 조건이 충족되지 않으면 즉시 중단하고 사용자에게 에러 원인을 보고해.

---

## 1단계 — tc-generate (테스트 케이스 설계 & DB 생성)
- `.claude/commands/tc-generate.md`의 지침을 그대로 실행해.
- **검증 조건**: 
  1. Notion DB가 성공적으로 생성되어야 함.
  2. 생성된 DB ID가 `.notion-db-id` 파일에 올바르게 기록되어 있어야 함.
- 검증 통과 시 **"✅ 1/3 tc-generate 완료 (Notion DB 연동 성공)"**을 출력하고 다음 단계로 진행해.

---

## 2단계 — tc-code (DOM 탐색 & 테스트 코드 작성)
- `.claude/commands/tc-code.md`의 지침을 그대로 실행해.
- **검증 조건**:
  1. `.notion-db-id` 파일에서 DB ID를 정상적으로 읽어와야 함.
  2. 실제 웹 탐색 후 `pages/{PROJECT_NAME}/selectors.json` 파일이 생성되어야 함.
  3. `tests/{PROJECT_NAME}/` 폴더 안에 `.spec.js` 테스트 파일이 생성되어야 함.
- 검증 통과 시 **"✅ 2/3 tc-code 완료 (테스트 코드 생성 완료)"**를 출력하고 다음 단계로 진행해.

---

## 3단계 — tc-run (테스트 실행, 자가 치유 & Notion 업데이트)
- `.claude/commands/tc-run.md`의 지침을 그대로 실행해.
- **검증 조건**:
  1. 테스트 실행 결과 리포트(`test-results/results.json`)가 정상적으로 생성되어야 함.
  2. 실패 케이스 발생 시 자가 치유(Self-healing) 프로세스가 동작해야 함.
  3. Notion DB의 각 TC 페이지 `통과여부`와 `마지막 실행`이 성공적으로 업데이트되어야 함.
- 검증 통과 시 **"✅ 3/3 tc-run 완료 (테스트 실행 및 결과 반영 완료)"**를 출력해.

---

## 최종 보고
모든 단계가 성공적으로 완료되면 아래 항목을 표와 요약으로 출력해 줘.

### 파이프라인 실행 결과 요약
- **프로젝트명**: `PROJECT_NAME`
- **설계된 총 TC 수**: N개
- **작성된 파일**:
  | 구분 | 파일 경로 |
  |---|---|
  | 페이지 객체 | `pages/{PROJECT_NAME}/*Page.js` |
  | 테스트 코드 | `tests/{PROJECT_NAME}/*.spec.js` |
- **최종 테스트 결과**: 
  - **전체**: N건 / **성공**: N건 / **실패**: N건 / **스킵**: N건
- **자가 치유 내역**: (AI가 스스로 수정한 셀렉터나 코드가 있다면 요약 기술)
- **Notion 업데이트 결과**: 완료 여부 및 DB 링크
