## 서비스 개요
- 서비스명: MyProject
- 대상 URL: https://your-service.com
- 주요 기능: 로그인, 회원가입, 메인 대시보드, 결제

## 핵심 비즈니스 로직

### 1. 인증 (로그인 / 로그아웃)
- 이메일 + 비밀번호 기반 인증
- 잘못된 정보 입력 시 에러 메시지 노출
- 이메일 형식 유효성 검사 (프론트)

### 2. 회원가입
- 이름 / 이메일 / 비밀번호 필수 입력
- 이메일 중복 확인
- 비밀번호 최소 8자, 영문+숫자 포함

### 3. 마이페이지
- 프로필 정보 수정
- 비밀번호 변경
